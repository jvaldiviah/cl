# Carpeta de Recursos (Assets)

Coloca aquí los archivos multimedia para la Landing Page:

### 📁 Estructura recomendada:
- **`assets/video/`**: Coloca aquí tu video principal (por ejemplo `video.mp4` o `promo.mp4`).
- **`assets/images/`**: Coloca aquí el logo, las imágenes de producto con fondo transparente (PNG/WebP) y cualquier otro gráfico.
